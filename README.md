# Format Bin

A gallery of 55 video formats, each with a reference code:

- `lemo:<slug>` — a Lemo-Opuscar style
- `ai:<skill>` — an AI_Animation skill
- `house:<name>` — a format saved from a reference reel

Open `index.html` in a browser to view the gallery. `template.html` is the source; `build_gallery.py` inlines `lemo.json` into `index.html`. Thumbnails live in `thumbs/`, source images in `raw/`.
